# Website Mô phỏng Quy trình Nghiệp vụ (BPMS) – FPT Long Châu

Website tương tác trực quan hóa 6 quy trình nghiệp vụ trọng điểm của FPT Long Châu theo chuẩn BPMN 2.0 (khớp với Chương 3 của Báo cáo Đồ án).

## 🚀 Cách mở xem trực tiếp trên máy (Không cần cài đặt)
1. Mở thư mục `website/`.
2. Nhấp đúp chuột vào file `index.html` để mở trên Google Chrome / Microsoft Edge / Firefox.

---

## 🌐 Cách Public lên Internet (Vercel / Netlify) trong 1 phút (Miễn phí 100%)

### Cách A: Kéo thả trực tiếp lên Netlify (Nhanh nhất - Không cần tài khoản GitHub)
1. Truy cập: [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Kéo toàn bộ thư mục `website` thả vào ô upload trên trình duyệt.
3. Đợi 15 giây, Netlify sẽ cấp ngay cho bạn một đường link trực tuyến HTTPS (ví dụ: `https://fpt-longchau-bpm.netlify.app`).

### Cách B: Triển khai qua Vercel
1. Đẩy code lên GitHub.
2. Đăng nhập [https://vercel.com](https://vercel.com) -> Chọn "Add New Project" -> Chọn Repository.
3. Ở ô **Root Directory**, bấm Edit chọn thư mục `website` -> Bấm **Deploy**.
4. Website sẽ online ngay lập tức với tên miền `https://longchau-bpms.vercel.app`!
